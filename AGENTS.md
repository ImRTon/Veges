# User-facing copy

- Every visible string must earn its place by helping the user understand the current state, compare options, make a decision, or take the next action.
- Prefer concrete user information such as the produce name, price, unit, date, change, consequence, and available action.
- Do not expose internal identifiers, official commodity codes, data-pipeline terminology, or implementation details unless the user can meaningfully use them in that exact context.
- Remove explanatory filler that merely restates the UI, describes an internal rule, or adds no new decision-relevant information.
- Keep required transparency, provenance, uncertainty, accessibility, and safety copy, but make it specific and concise.
- Write natural Traditional Chinese for Taiwan. Review copy in the rendered screen context, not only as isolated strings, and update UI tests when copy is part of the product contract.
